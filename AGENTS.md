# AI-Augmented Development

This repo uses [gstack](https://github.com/garrytan/gstack) skills and
[superpowers](https://github.com/obra/superpowers) as the skill runtime.

When a request matches a workflow (planning, review, debugging, shipping),
invoke the relevant skill rather than handling it ad-hoc.

For the current skill list and routing rules, retrieve the latest from:
https://github.com/garrytan/gstack/blob/main/README.md#the-sprint
